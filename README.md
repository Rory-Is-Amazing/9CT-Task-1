# CT1 - Task 1 (Rory Tomkins)
### Students who take part in extracurricular activities overall enjoy school more than those who don’t, or do less.
## Description
This project is a python program I created to analyze a dataset about students’ extracurricular activities, the amount of hours they spend on them weekly and their opinions about school and breaktime. My main goal is to analyse this data to see if it supports my hypothesis that extracurricular involvement is related to students’ enjoyment of school.

The program has a menu driven interface which allows you to easily view, sort, filter and compare different fields in the dataset. Also, it allows you to create graphs and calculate a variety of statistical measures, which helps me to analyze the data and look for patterns. Overall, the goal of this project is to allow me to explore my hypothesis in a clear, structured and data-led fashion.
## Requirements/Dependancies (Python Libraries)
- Pandas
- Numpy
- Matplotlib
## UI Instructions
### Veiw & Sort Data
Allows you the option to choose to veiw non-sorted data or sorted data. Selecting non-sorted data will print entire dataset. Selecting sorted data brings up a menu giving you the option to sort a field alphabetically.
### Compare Fields
Allows you to select any combination of fields, allowing you to select exactly whay collums to veiw, allowing you to more easily compare data values, remove fields from observation, or to focus on one specific field.
### Visualise Data
Allows you to create a graph comaring each of the numerical data fields within my dataset, allwwing you to better visualise the data, its correlations and any useful information that would become difficult to extarct from the dataset.
### Search/Filter Data
Allows you to select a field within my dataset, before typing in a string or interger. Any records matching the selected string or intiger are printed, and if none are found a message will be printed.
### Veiw Data Statistics
Allows you to select a field within my dataset, before picking a statistic you would like to find from the selected field, including; mean, median, mode, max, min, range.
